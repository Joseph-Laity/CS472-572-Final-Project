Density-Based Clustering of Earth-like Planetary Data

Overview

This project explores clustering of planetary atmospheric compositions using density-based algorithms. We compare DBSCAN and HDBSCAN to identify Earth-like planets based on gas composition similarity.

Methodology

  • Selected atmospheric features (H2O → NO2)
  • Standardized data using StandardScaler
  • Applied DBSCAN clustering
  • Projected clusters using PCA

Earth Reference

Earth was added as a reference vector and assigned to the nearest cluster using Nearest Neighbors.

PCA Visualization

Results

HDBSCAN outperformed DBSCAN by reducing noise and producing more meaningful clusters. DBSCAN required careful tuning of epsilon and still resulted in significant noise points.
